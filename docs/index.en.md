# SRHarness

SRHarness is a research runtime for agentic symbolic regression. Language models inspect data, propose formulas, fit parameters, and validate candidates through a controlled tool set. Search steps, tool results, model usage, and candidate formulas are retained as auditable run records.

## Where to start

- [Install](install.md): install SRHarness and optional dependencies
- [Quick Start](quick-start.md): complete your first run
- [Examples](examples.md): explore regression, ODE, and tool-call examples
- [SRHarness](sr-harness.md): understand commands, runtime options, and output files
- [SRHarness WebUI](web-ui.md): complete an interactive search in the browser
- [SRHarness Engine](engine.md): learn the expression syntax, parameters, and graph structures
- [API Reference](/reference/): look up Python types and method signatures
