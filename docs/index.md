# SRHarness

SRHarness 是一个面向智能体符号回归的研究运行时。语言模型可以在受控工具集上检查数据、提出公式、拟合参数和验证候选；搜索过程、工具结果、模型用量与候选公式会被组织为可审计的运行记录。
